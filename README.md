# JohnsonXCorp — studio website

Live at **https://thepastor.github.io/**

The home page of JohnsonXCorp, an independent software studio in Kamloops, BC. It
describes, shows and links the studio's products:

- [Read Fast](https://thepastor.github.io/read-fast/) — speed reading
- [UNI Made EZ](https://thepastor.github.io/uni-made-ez/) — study tools
- [Vamos](https://thepastor.github.io/vamos/) — language learning
- [Syllabus Desk](https://thepastor.github.io/syllabus-desk/) — term planning

A static site: one `index.html`, screenshots in `images/`, served by GitHub Pages
from the `main` branch. There is no build step.
